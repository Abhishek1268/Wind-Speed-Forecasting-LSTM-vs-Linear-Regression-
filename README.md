# LSTM Wind Speed Forecasting Model

## Overview
Deep learning model for wind speed forecasting using 
Long Short-Term Memory (LSTM) neural networks — 
developed as part of M.Eng. Smart Energy Systems 
at Hochschule Ansbach, Germany.

The model was compared against a linear regression 
baseline to evaluate forecasting performance on 
real-world wind measurement data.

## Dataset
- 10,681 hourly wind speed measurements
- 14 months of continuous data
- Data preprocessing: cleaning, feature engineering, 
  MinMax normalisation

## Methodology
- LSTM neural network for time-series forecasting
- Linear regression baseline for comparison
- Train/test split and model validation
- Evaluation metric: Mean Squared Error (MSE)

## Results
- Baseline MSE (Linear Regression): 2.107
- LSTM Validation Loss: 1.34e-06
- LSTM outperformed linear regression baseline 
  significantly on wind speed prediction accuracy

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- TensorFlow / Keras

## Project Context
Developed as part of M.Eng. Smart Energy Systems 
coursework — demonstrating application of deep 
learning to renewable energy forecasting. 
Accurate wind speed forecasting is critical for 
yield estimation and grid integration of wind 
energy projects.
